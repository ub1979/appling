Background jobs as code.

Retries, schedules and fan-out in one function call — for Node, Python and anything that speaks HTTP. No queue to run.

    One call
    
Define it once. Ferry runs it, retries it, reports it.

    

      

        

          
          
          
        


import { ferry } from "@ferry/sdk"

export const sendReceipt = ferry.job("send-receipt", {
  retries: 5, backoff: "exponential",
}, async ({ orderId }) => {
  await emailReceipt(orderId)
})

// anywhere in your app
await sendReceipt.enqueue({ orderId: "ord_8213" })


from ferry import job

@job("send-receipt", retries=5, backoff="exponential")
async def send_receipt(order_id: str):
    await email_receipt(order_id)

# anywhere in your app
await send_receipt.enqueue(order_id="ord_8213")

    Features
    
The code is the config.

    

      

        
Schedules
Cron or plain words. Deploys update the schedule; nothing to sync.


ferry.schedule("nightly-report",
  "every day at 02:00", buildReport)

        
next run
Tue 02:00UTC
Wed 02:00UTC

      

      

        
Fan-out
Split one job into thousands and wait for all of them, with a concurrency cap.


await ferry.map(users, resizeAvatar,
  { concurrency: 50 })

        
12,400 runs
done12,388
retrying12

      

      

        
Idempotency
Same key, same result. Double clicks and webhook replays run once.


charge.enqueue(input, {
  key: `charge:${order.id}` })

        
deduplicated
2 requests1 run
